# Brief: Fleeting promo

- **For:** Instagram (Reels), promoting Fleeting, an app for last-minute flash deals from local
  restaurants, fitness classes, salons and spas, expiring the same day.
- **Who watches:** people scrolling Instagram in a city (the app opens on Dubai), deal-hunters, 20 to 40.
- **Length:** 20 s, 60 fps (1200 frames).
- **Format:** 9:16, 1080x1920 only.
- **Words:** written by Claude (see `src/data/timeline.json`), English.
- **Call to action:** "Grab it before it's gone." with the Fleeting wordmark.
- **Brand:** Fleeting orange (#F97316, Tailwind orange-500) as the one accent; warm dusk world.
  No logo file supplied: the wordmark is set in type.
- **Content:** deal cards use the app's own demo deals (Sunset Dhow Cruise Dinner, Pilates Reformer,
  Keratin & Blowout, Royal Hammam), all fictional businesses. Discounts 25 to 50 %.
- **Audio:** none supplied, so the film is silent. Cues are planned so music and effects can be
  dropped in later.
